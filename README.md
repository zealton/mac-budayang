# Mac不打烊 (mac-budayang)

给 Claude Code / Codex 一台不打烊的海外 Mac mini。

聚合多家海外 Mac mini 云租赁服务：实时比价、自动备份、故障自动切换、中文客服。
用户只对一家付款，我们在背后调度多家上游（Agent.Space、Lumio、My Remote Mac、Mac Mini Vault 等），哪家有货、哪家性价比高走哪家。

## 本仓库

- `index.html`：比价 + 落地页（单文件，无构建步骤），部署在 Vercel
- 价格与库存数据每日巡检更新

- Pro 版 1899 元/月：小时级备份，共享热备池，自动切换目标 30 分钟
- 团队版 1699 元/台/月（3 台起）：Pro 全部能力 + 统一账单
